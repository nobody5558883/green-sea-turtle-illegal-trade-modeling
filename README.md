# Combating Illegal Trade in Green Sea Turtles

## Project Overview

This research project develops a multi-model strategy for monitoring and reducing the illegal trade of green sea turtles. It combines statistical forecasting, movement simulation, resource allocation, and patrol-route optimization.

The project was completed as a team research project and was later developed into a conference paper published in *Highlights in Business, Economics and Management*.

## Research Question

How can statistical modeling, wildlife tracking technology, and optimization methods be combined to improve the monitoring and prevention of illegal wildlife trade?

## Methods

- ARIMA time-series forecasting
- RFID-based wildlife monitoring
- Agent-based sea turtle movement modeling
- Sequential Least Squares Programming for resource allocation
- Ant Colony Optimization for patrol-route planning
- Monte Carlo simulation for project evaluation

## Key Findings

The model estimated a 34.43% reduction in illegal wildlife trade after implementing the proposed monitoring and patrol strategy. The analysis also showed how seasonal movement patterns and resource constraints can affect wildlife protection decisions.
